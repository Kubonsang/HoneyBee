# HoneyBee 0.1.0-beta.6

Candidate release notes. Not published.

Built-in PowerShell now stays available while switching tabs, Workspaces, and projects. Close a
terminal explicitly when finished; app exit asks before ending running terminals. Workspace removal
requires its built-in terminal to close first. The app supports 16 sessions with bounded output and
preserves exited output until you open a new terminal or close it.

Workspace screens distinguish unknown Git, stale refresh results, repair-required, and incomplete
removal. Failures show their task target and bilingual recovery steps, with original diagnostic
codes in details. Diff loading no longer blocks unrelated mutation controls.

This candidate is for controlled evaluation on an existing matching hb8 storage installation.
Fresh installation and Beta 3 upgrade are not qualified. The storage component and protocol are
unchanged from Beta 5. Reboot recovery remains explicit through Workspace repair.

See [Beta 6 readiness](../validation/beta6-readiness.md) for validation and remaining release gates.
